# 传送书签：测试计划

## 1. 已知目标环境

沿用参考项目 `MultiplayerNpcLocator` 已经验证过的环境：

| 项目 | 目标值 |
|---|---|
| 操作系统 | Windows 11 |
| 游戏 | Stardew Valley 1.6.15 build 24356 |
| SMAPI | 4.5.2 |
| .NET | .NET 6 SDK x64 |
| GMCM | 1.16.0，可选 |
| 联机 | 一名主机 + 至少一名加入者 |
| 参考共存 Mod | NPC Locator、MouseMoveMode（如测试端已有） |

当前开发机是 Apple Silicon macOS，参考项目记录显示没有本地游戏、SMAPI 程序集和可用 `dotnet` SDK。因此实际编译、加载和联机验收必须在 Windows 游戏环境完成，不能以静态代码检查替代。

## 2. 构建策略

参考项目的 `scripts/Build-Windows.ps1`：

- 检查 .NET 6 SDK；
- 自动或显式寻找含 `Stardew Valley.dll` 与 `StardewModdingAPI.dll` 的游戏目录；
- `dotnet restore` 后 `dotnet build --no-restore`；
- 默认不自动部署；
- `-Install` 只在安全目标下安装；
- 更新时先核对目标 `manifest.json` 的 UniqueID；
- 检测旧目录，避免同一 Mod 被加载两次；
- Release 包输出 SHA-256。

## 3. 核心测试矩阵

### 存档与玩家

- 新存档、已有存档；
- 农场主、联机加入者；
- 玩家改显示名；
- 小屋移动；
- 断线重连；
- 次日继续；
- 返回标题后切换另一个存档；
- 没安装 Mod 的玩家加入。

### 地点类型

- 农场、城镇、森林、山区、海滩；
- 农舍、温室、酒窖；
- 两个以上同类型畜棚/鸡舍；
- 两个以上玩家小屋；
- 可移动农场建筑；
- 商店和 NPC 房间；
- 沙漠、下水道、姜岛等解锁区域；
- 矿井入口与随机层；
- 火山入口与随机房间；
- 节日、事件、小游戏；
- SVE 或至少一个标准自定义地图测试档。

### 安全格

- 正常空格；
- 水、墙、地图边缘与越界；
- 箱子、家具、建筑、作物或大物体；
- NPC、动物、马和其他玩家；
- 原格阻挡但半径 1/2/3 有安全格；
- 三格内完全没有安全格。

### 玩家状态

- 走路、跑步；
- 钓鱼；
- 使用工具；
- 骑马；
- 对话、商店、箱子；
- 受到伤害；
- 战斗；
- 节日、事件、婚礼、小游戏；
- 昏迷、睡觉和 2:00 AM 边界。

## 4. 功能测试

### 书签

- 创建、重名、附近重复、编辑、收藏、排序；
- 删除确认、撤销、重新绑定；
- 数十个地点下搜索和滚动；
- 地图来源 Mod 卸载后失效，再安装后恢复；
- 建筑移动、升级、拆除后的结果。

### 上一个位置

- A → B 后返回 A；
- 连续 A ⇄ B；
- 传送失败不覆盖；
- 步行不覆盖；
- 睡觉、昏迷、读档和返回标题清空；
- 禁止地图不写入。

### 坐标

- 支持的文本格式；
- 中文显示名与内部名；
- 当前地图默认值；
- 负数、超大数、非整数、空值、超长文本；
- 地图不存在、未访问、不可站立；
- 修正落点提示；
- 复制后再次粘贴；
- 传送后另存为书签。

## 5. UI 测试

- 100%、125%、150% UI 缩放；
- 1280×720 及更高分辨率；
- 窗口/全屏；
- 英文和简体中文；
- 长地点名和长错误文本；
- 鼠标、键盘、手柄完整闭环；
- 搜索框输入 `E`、`T`、菜单键等不会误关闭或触发游戏；
- 羊皮纸没有横向色带、偏白遮罩或黑色分栏；
- 游戏场景在菜单后保持可见；
- 联机界面明确提示游戏不会暂停。

## 6. 联机测试

1. 双方安装同一构建；
2. 双方创建同名但不同坐标的书签；
3. 确认列表、收藏和历史互不出现；
4. 双方同时传送到同一目标附近；
5. 一方在节日/钓鱼，另一方正常使用；
6. 加入者断线重连，确认数据持久化；
7. 加入者改名和小屋移动；
8. 只安装主机、只安装加入者和双方都不安装的兼容冒烟；
9. 查看双方完整 SMAPI 日志，确认无超时、反序列化或未处理异常。

## 7. 每阶段回传证据

- PowerShell 从 SDK 检测到构建成功的完整输出；
- SMAPI 完整日志链接；
- 指定探针命令输出；
- 单人和联机关键界面截图；
- 测试当天是否为普通日、雨天、节日或事件日；
- 使用的存档类型、地图 Mod 和双方安装组合。
