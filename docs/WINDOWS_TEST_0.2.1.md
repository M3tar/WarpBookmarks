# 传送书签 0.2.1：Windows 输入快速复核

本轮只检查用户反馈的三个输入问题。

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\Build-Windows.ps1 -Install
```

1. 打开一个自定义书签的“重命名”，在文字中使用左右方向键，确认光标可以移动和插入文字。
2. 打开“精准坐标”，确认地图改为下拉选择，不再要求手输 `Town`、`Farm` 等内部名称。
3. 下拉地点应显示类似“鹈鹕镇 (Town)”的名称；可用鼠标滚轮或上下方向键浏览。
4. 在 X 输入 `42` 后按右方向键或 Tab，应切换到 Y；输入 `68` 后可以预览。
5. 在 Y 中按左方向键应返回 X。预览、保存和传送沿用上一版逻辑。

如果没有红色错误，只需说明方向键与下拉框是否正常。
