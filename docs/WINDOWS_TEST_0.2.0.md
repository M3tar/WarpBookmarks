# 传送书签 0.2.0：Windows 功能复核

本轮只需要检查搜索和精准坐标，不重复测试已经通过的基础书签功能。

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\Build-Windows.ps1 -Install
```

## 搜索

1. 按 K 打开手册，点击右上方搜索框。
2. 输入已有书签名称的一部分，应只显示匹配结果。
3. 输入 `Farm`、`Town` 等内部地图名也应能过滤；清空后恢复完整列表。
4. 输入文字时，W/S 等字母不应意外移动地点选择。

## 精准坐标

1. 点击手册底部“精准坐标”。窗口默认填入当前地图和玩家坐标。
2. 输入 `Town 42 68`，点击“预览”；应显示解析后的地图和实际安全落点，不能未经预览直接传送。
3. 可再检查 `Town, 42, 68` 或 `Town (42, 68)`；只输入 `42 68` 时使用当前地图。
4. 点击“保存为书签”，返回手册后应能搜索到它。
5. 再次预览一个地点并点击“传送”，确认正常到达。
6. 输入不存在的地图、非数字坐标或特殊随机地图，应说明拒绝原因而不是传送。

关闭精准坐标窗口或按 Esc 应返回传送手册。若没有红色错误，只需要说明搜索、预览、保存和传送是否正常。
