# 传送书签：产品决策记录

## 已确认

### D-001：项目名称

- 中文名：传送书签
- 英文名：Warp Bookmarks
- 工程标识：`WarpBookmarks`

### D-002：不制作实体道具

原因：避免占用背包格和频繁切换工具栏。传送手册是快捷键打开的 UI，不是游戏物品。

### D-003：不加入成长和资源系统

不实现等级、升级、充能、材料消耗、制作配方和冷却。产品重点是减少重复赶路。

### D-004：用传送手册取代罗盘

罗盘只适合少量地点。地点较多、需要搜索、删除、隐藏和坐标输入时，分类列表与详情页更可扩展。

### D-005：联机只做个人化兼容

每名玩家的数据独立；不共享书签，不传送队友，不实现邀请和队伍传送。

### D-006：支持精准坐标

坐标目标必须包含地图和格子 X/Y；支持复制、粘贴、预览、一次性传送和另存为书签。

### D-007：删除与隐藏区分

自定义书签可以删除；系统默认地点只能隐藏并可恢复。

### D-008：快速入口与完整管理合并在手册中

首页/收藏用于快速传送，地点库用于搜索和管理。收藏位置固定，不根据最近使用自动重排。

### D-009：统一安全传送管线

回家、书签、上一个位置、默认地点和坐标输入必须经过同一套状态、地图、权限和安全格验证。

### D-010：参考 NPC Locator 的视觉与测试基线

沿用原版羊皮纸、文本框、字体和棕金交互色；首发实测采用相同的 Windows 11、游戏 1.6.15、SMAPI 4.5.2 和双人联机环境。

### D-011：默认地点

首版内置农场、山区、海滩、沙漠和姜岛五个原版标准传送图腾目的地；严格遵守解锁与当前访问条件。

### D-012：返回住宅落点

返回当前玩家自己的住宅门外，不传送到室内床边。

### D-013：严格访问控制

精准坐标、自定义书签和默认地点都不能绕过未解锁地图、原版当前进入条件、节日与事件限制。

### D-014：默认快捷键与提示

最初采用 F4/Shift+F4，Windows 实测发现会触发游戏原生截图模式；后续短暂测试 F6 和 T。最终按用户选择确定为 `K` 打开手册、`Shift+K` 记录当前位置。旧 F4/F5/F6/T 测试绑定自动迁移一次，其他玩家自定义键不覆盖。输入使用 SMAPI `ButtonsChanged` 与 `SuppressActiveKeybinds`，避免组合键重复触发和游戏同时处理。

### D-015：1.0.0 功能冻结

`0.5.3` 已完成 Windows 单人与在线联机实机验证，其核心行为作为 `1.0.0` 的发布基线。首版前不再增加传送入口或管理功能，只处理发布文档、打包与阻断性问题。

### D-016：失效书签管理延期

当前传送管线已能在点击传送时提示地图缺失、特殊地图限制和附近无安全落点，并会在可能时自动调整到附近安全格。书签列表的预先失效标记、失效原因详情与“重新绑定当前位置”延后到 `1.x`。

### D-017：首版延期增强

图标、颜色、收藏手动排序、删除撤销、坐标复制/粘贴、动画与完整手柄适配不阻塞 `1.0.0`，统一进入发布后候选池。

## 建议默认、等待实测

### P-001：书签数量

建议不设低数量上限，让搜索、分类和滚动承担规模问题。
