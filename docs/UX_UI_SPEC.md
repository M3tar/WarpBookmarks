# 传送书签：UI 与交互规格

## 1. 设计来源

本项目 UI 以 `/Users/mercury/Claude+Codex+Code/MultiplayerNpcLocator` 的实际实现为基线：

- 使用游戏资源 `LooseSprites\\letterBG` 的 `(0,0,320,180)` 羊皮纸区域；
- 按 16:9 比例绘制，窗口后保留实时游戏场景；
- 搜索框使用 `LooseSprites\\textBox`；
- 正文优先使用 `Game1.smallFont` 与 `Game1.textColor`；
- 标题使用 `Game1.dialogueFont`；
- 按钮使用原版 `drawTextureBox`；
- 不复制其他 Mod 的图片资源，不依赖参考项目 DLL。

参考项目实测曾出现大纹理拉伸色带、偏白覆盖层和搜索框按键被基础菜单重复处理的问题；本项目从第一版就规避这些问题。

## 2. 主界面：传送手册

默认按可见区域居中显示，设计尺寸 960×540；在 UI 缩放或低分辨率下按视口安全范围缩放和重排。

```text
┌──────────────────────────────────────────────────────────┐
│ 传送书签                                  [搜索地点……] × │
├──────────────┬──────────────────────┬────────────────────┤
│ ⌂ 返回住宅   │ ★ 温室门口           │ 温室门口           │
│ ↩ 上一位置   │ ★ 矿井入口           │ 区域：农场         │
│ ★ 收藏       │   猪舍               │ 地图：Greenhouse   │
│ 我的书签     │   酒窖               │ 坐标：12, 23       │
│ 默认地点     │   森林钓鱼点         │ 状态：可用         │
│ 最近使用     │                      │                    │
│ 已隐藏       │                      │ [传送] [编辑]      │
│              │                      │ [复制] [删除]      │
├──────────────┴──────────────────────┴────────────────────┤
│ [记录当前位置] [精准坐标]                  [关闭]         │
└──────────────────────────────────────────────────────────┘
```

### 三栏职责

- 左栏：系统动作与分类；
- 中栏：可滚动地点列表；
- 右栏：地点详情、状态和操作；
- 顶部：即时搜索；
- 底部：创建书签、坐标传送与关闭。

## 3. 首页与快速使用

打开手册时默认进入“收藏”。若没有收藏，则显示简短引导，不自动塞入默认地点。

固定快速动作：

- 返回住宅；
- 上一个位置；
- 记录当前位置；
- 精准坐标。

收藏顺序固定，由玩家手动调整。最近使用只作为独立分类，不自动改变收藏位置。

## 4. 搜索行为

- 搜索显示名称、内部地图名和可选别名；
- 输入时实时过滤；
- 支持中文、英文与大小写不敏感匹配；
- 搜索框选中时，文字按键不得继续传给基础菜单；
- `Esc`、当前菜单快捷键和右上角按钮仍可关闭；
- 检测到“地图名 + 两个整数”时显示坐标解析卡片，不自动传送。

## 5. 精准坐标窗口

```text
┌──────────────────────────────┐
│ 精准传送                     │
│ 地图：[鹈鹕镇 (Town)     ▼] │
│ X：[42]   ，   Y：[68]       │
│                              │
│ 解析结果：鹈鹕镇 (42, 68)    │
│ 状态：可用                   │
│                              │
│ [预览] [保存为书签] [传送]   │
└──────────────────────────────┘
```

地图使用当前玩家已经到访且当前存在的地点下拉列表，同时显示本地化名称和内部名称；未访问、随机层和临时特殊地图不进入列表。展开列表后可按本地化名称或内部名称搜索。X/Y 使用两个独立整数输入框，只通过鼠标点击切换，避免同一按键经过两条输入通道造成焦点来回跳转。

无效输入必须说明具体原因：地图不存在、坐标越界、未访问、特殊地图或附近无安全格。

## 6. 视觉配色

优先使用原版资源与颜色，不建立独立高饱和主题。

| 用途 | 基线 |
|---|---|
| 背景 | `letterBG` 原版羊皮纸，保持 16:9 |
| 正文 | `Game1.textColor` |
| 错误 | `Color.DarkRed` |
| 选中行 | `Color.SandyBrown * 0.35f` |
| 手柄焦点 | `Color.Wheat * 0.45f`，实机检查是否偏白 |
| 普通悬停 | 棕金半透明色，避免纯白大面积覆盖 |
| 选中分页 | `new Color(196,135,70) * 0.55f` |
| 分页悬停 | `new Color(222,184,120) * 0.4f` |
| 未选分页 | `new Color(120,78,48) * 0.12f` |
| 不可用 | `Color.DarkGray`，同时配文字/图标，不只依赖颜色 |

收藏、警告和不可用状态必须有图标或文本标签，保证色觉差异不影响理解。

## 7. 快捷键

所有按键使用 SMAPI `KeybindList` 并支持 GMCM 修改。

暂定建议：

- `K`：打开传送手册；
- `Shift + K`：记录当前位置；
- 精准坐标和显示当前位置不默认占用额外按键，可由玩家自行绑定。

最终按用户选择采用 K/Shift+K，不再使用功能键，也避开 T 的输入/聊天用途。Windows 实测确认 F4 会触发游戏截图模式，因此永久排除 F4。Mod 在触发后抑制游戏继续处理；如 K 与其他 Mod 冲突，玩家可在 GMCM 或 `config.json` 中改绑。

默认键位已经确认，但必须支持通过 GMCM 和 `config.json` 编辑。为避免玩家忘记 `Shift + K`：

- 每次载入存档后的首次提示显示“当前手册快捷键打开传送手册；当前记录快捷键记录当前位置”；默认绑定时即为“K / Shift + K”；
- 提示可以在配置中关闭；
- 手册底部始终显示当前实际绑定，而不是写死文本；
- “记录当前位置”按钮的悬停说明同时显示快捷键；
- 玩家修改绑定后，所有提示立即使用新绑定。

## 8. 鼠标、键盘与手柄

### 键盘

- 上下或 `W/S`：移动列表焦点；
- 左右：切换分类/详情；
- `Enter`：选择或确认；
- `Delete`：发起删除/隐藏，必须二次确认或可撤销；
- `Esc`：返回或关闭。

### 手柄

- 方向键/摇杆：移动焦点；
- A：选择/传送；
- X：收藏或取消收藏；
- Y：打开编辑；
- B：返回/关闭；
- 肩键：切换分类。

所有可点击元素必须建立邻接导航；不能只做到鼠标可用。

## 9. 反馈与动画

- 选择后显示目标、坐标和修正落点预览；
- 使用短暂原版图腾风格淡出/粒子动画；
- 动画期间移动、受伤或状态改变则取消；
- 失败不更新历史；
- 如果落点从 `(42,68)` 修正为 `(43,68)`，明确提示；
- 联机菜单不暂停游戏，界面顶部显示提示。

## 10. 删除、隐藏与失效

自定义书签详情按钮为“删除”；默认地点按钮为“隐藏”。

失效书签示例：

```text
⚠ 旧猪舍
原建筑已经不存在。

[在当前位置重新绑定] [编辑] [删除]
```

删除后显示会话内撤销提示；隐藏地点进入“已隐藏”分类，可恢复全部默认地点。
