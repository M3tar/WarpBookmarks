# 传送书签 0.5.2 Windows 合并测试

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\Build-Windows.ps1 -Install
```

确认 SMAPI 启动日志显示 `Warp Bookmarks 0.5.2`，且没有红色错误。

## 本轮重点

1. 打开“输入坐标…”，选择木匠的商店并输入 `18`、`4`。
2. 预览成功后直接传送。
3. 左下角成功提示应类似“已传送至 木匠的商店（18, 4）。”，坐标只出现一次。
4. 从手册传送到普通自定义书签、默认地点或住宅，成功提示只显示地点名称，不会再统一追加一组坐标。
5. 如果目标格被占用并由安全检查移动到附近格子，提示会额外显示“安全落点调整为（实际 X, 实际 Y）”；不方便构造占用格时可以跳过此项。

顺带确认 0.5.1 的主传送按钮启用时仍为明亮原版颜色、载入存档时没有快捷键 HUD、手册内快捷键文案仍随当前配置变化。重命名左右方向键仍是已知问题，本轮无需复测。
