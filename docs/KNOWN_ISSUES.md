# 已知问题

## 重命名文本框的左右方向键不移动光标

- 影响版本：`1.0.0–1.0.1`。
- 环境：Stardew Valley 1.6.15、SMAPI 4.5.2、Windows。
- 表现：重命名书签时可以输入和删除字符，但 Left/Right 不移动插入光标。
- 已排除：原版 `NamingMenu` 与 Mod 自定义羊皮纸窗口均出现；菜单也已经在文本框聚焦时停止调用基础导航处理，因此不是简单的菜单抢键。
- 当前判断：游戏 `TextBox` 的特殊方向键没有通过当前键盘分发路径更新内部光标。继续修复可能需要直接调用未充分验证的特殊输入方法、访问内部光标状态，或自建文本编辑控件。
- 临时办法：退格后重新输入名称；不影响保存、搜索、传送和其他书签数据。
- 处理决定：暂缓，等主要功能稳定后再单独验证，不使用反射强改游戏内部字段。
