# 传送书签 0.5.3 Windows 合并测试

## 1. 安装与启动

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\Build-Windows.ps1 -Install
```

确认 SMAPI 启动日志显示 `Warp Bookmarks 0.5.3`，且没有红色错误。

## 2. 存档与玩家隔离

这项需要能进入在线联机存档时再测，不必阻塞本次单人测试。

1. 进入在线联机存档，新建一个唯一名称的书签，例如 `0.5.3-联机专用`。
2. 在 SMAPI 控制台输入 `wb_dump_bookmarks`，保留 `Bookmark data owner` 和书签列表。
3. 返回标题画面，进入个人存档。
4. 确认手册中没有 `0.5.3-联机专用`，再执行 `wb_dump_bookmarks`；其中的 `save` 和 `player` 应与联机存档不同。
5. 在个人存档新建 `0.5.3-单人专用`，返回联机存档，确认它也没有出现。

> 注：修复前已经串入个人存档的旧书签仍会存在。Mod 不能安全判断它们是否为玩家原本的数据，所以不会自动删除；请在确认后手动删除。测试必须使用升级后新建的唯一名称。

## 3. 单人基础回归

1. `K` 打开和关闭手册，`Shift + K` 快速记录当前位置。
2. 书签可搜索、收藏、重命名、删除和传送。
3. 精准坐标传送的成功提示只显示一次坐标；只在安全落点被调整时额外显示实际坐标。

## 4. 如果发现异常

请提供：

- 完整 SMAPI 日志；
- 两个存档中各执行一次 `wb_dump_bookmarks` 的输出；
- 串入书签是在升级前还是升级后创建。
