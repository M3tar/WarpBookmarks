# 传送书签 0.2.2：Windows 输入快速复核

本轮不再测试已登记的重命名方向键问题，只检查坐标字段焦点和地图搜索。

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\Build-Windows.ps1 -Install
```

1. 打开精准坐标，点击 X 并输入；按 Right 或 Tab 不应再自动切换字段。
2. 只把鼠标移到 Y 上时不应改变焦点；点击 Y 后才应在 Y 中输入。
3. 展开目标地图下拉框，输入中文显示名的一部分或 `Town`、`Farm` 等内部名称，应即时过滤。
4. 清空搜索后恢复完整的已到访地图列表；鼠标滚轮和上下键仍可浏览。
5. 选择搜索结果后，原有预览、保存和传送应继续可用。

如果没有红色错误，只需说明字段焦点是否稳定、地图搜索是否正常。
