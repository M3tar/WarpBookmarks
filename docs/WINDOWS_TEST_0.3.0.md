# 传送书签 0.3.0：Windows 分类与 UI 复核

本轮把上次尚未复核的坐标焦点/地图搜索，与新的分类界面一起测试。

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\Build-Windows.ps1 -Install
```

## 精准坐标传送

1. 底部按钮应显示“精准坐标传送”，三个底部按钮都在羊皮纸外框内，文字不应明显挤压或越界。
2. 坐标窗口中，Right 和 Tab 不再自动切换 X/Y；仅移动鼠标到另一个输入框也不切换，点击后才切换。
3. 地图下拉框可以输入中文显示名或 `Town`、`Farm` 等内部名称进行过滤。

## 地点分类

1. 手册列表上方显示“全部、收藏、我的书签、默认地点、已隐藏”，五个分类不应互相重叠。
2. “收藏”只显示已收藏地点；在该分类取消收藏后，该地点应立即离开列表。
3. “我的书签”只显示自定义书签；“默认地点”只显示未隐藏的默认地点。
4. 隐藏一个默认地点后，进入“已隐藏”应看到它；隐藏地点的传送与收藏按钮不可用，点击“恢复”后重新出现在默认地点中。
5. 顶部搜索与当前分类同时生效，清空搜索后恢复该分类的完整列表。

重命名左右方向键是已记录问题，不需要重复测试。如果没有红色错误，只需说明坐标焦点、地图搜索、分类和按钮布局是否正常。
