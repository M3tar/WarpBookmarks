# 传送书签 1.0.1 Windows 发布测试

本轮重点验证英文布局、长文本边界，以及中文创建的书签在英文界面中的可读性。请保留关键截图和完整 SMAPI 日志。

## 1. 构建并安装

在项目根目录打开 PowerShell：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\Build-Windows.ps1 -Install
```

如果脚本无法找到游戏：

```powershell
.\scripts\Build-Windows.ps1 -GamePath "C:\Program Files (x86)\Steam\steamapps\common\Stardew Valley" -Install
```

确认 SMAPI 显示 `Warp Bookmarks 1.0.1`，并且没有本 Mod 的红色错误。

## 2. 英文布局

1. 将游戏语言切换为 English，载入存档并按 `K` 打开手册。
2. 确认 `Quick Access / All / Bookmarks / Defaults / Hidden` 横跨手册完整显示，互不重叠，也没有省略号。
3. 确认顶部不再单独绘制 `Search` 标签；空搜索框内部显示 `Search…`，点击输入后提示消失，标题和输入框之间有清楚间距。
4. 依次进入 `Defaults` 和 `Hidden`；右侧详情从分类栏下方开始，不遮挡分类。
5. 隐藏地点全部恢复后进入 `Hidden`，确认 `There are no hidden default destinations.` 在右侧区域内换行或完整显示，不越过羊皮纸。
6. 选择 `Farm totem`，确认详情显示为 `Area: Farm`、`Map: Farm`、`Tile: ...`、`Source: Standard destination`，没有方块、叉号或连续异常字符。
7. 检查底部三个按钮和快捷键说明均在羊皮纸范围内。
8. 打开 `Enter coordinates...`，确认地图选择框右侧显示清晰的向下像素三角形；展开后变为向上三角形，不能显示为 `?`、叉号或其他字体缺字符号。
9. 确认底部 `Preview / Save bookmark / Warp` 三个按钮完整显示，尤其是中间按钮文字不能越过按钮边框。
10. 当地点数量超过六项时，确认主列表滚动条底端与第六行底边对齐，不再向下多出一截。

## 3. 中文书签跨语言显示

1. 切换为简体中文，创建书签 `温室门口`，再创建一个中英混合书签 `Farm 北门`。
2. 退出到标题画面，将游戏语言切换为 English，再载入同一存档。
3. 打开 `Bookmarks`，确认 `温室门口` 与 `Farm 北门` 都能直接阅读，名称本身不显示方块、问号或连续叉号。
4. 依次选中两个书签，确认列表、右侧标题、详情字段和底部 `Warp to ...` 按钮都能显示中文；中文字号应接近所在位置的英文字号，不能明显放大、下沉或挤到按钮边框。
5. 点击 `Pin` 将 `温室门口` 加入常用，确认提示为 `Pinned to Quick Access.`，地点出现在 `Quick Access` 分类中；点击 `Unpin` 后移出该分类（住宅和上一个位置仍固定保留）。
6. 确认加入常用后，列表行的最右侧显示小型实心金色像素星；名称仍与未加入常用的项目左对齐，星标和中文之间有明显空隙，也没有 `?`。
7. 在搜索框输入 `温室`，确认可以找到 `温室门口`，且输入框中的中文可见。
8. 打开重命名窗口，确认原中文名称在输入框中可见；追加或删除一个字符后保存。
9. 传送到该书签，确认传送功能正常；如果 HUD 中的名称仍存在缺字，请单独截图记录。
10. 再切回简体中文，确认两个名称及修改结果保持不变，没有被自动翻译或覆盖；操作显示为“加入常用 / 移出常用”。
11. 选择中文名称并检查右下角主按钮显示为“传送到 地点名称”，地点名前后不能出现 `?`。
12. 确认顶部第三个分类显示为“书签”，文字连续、居中；“默认地点”等其他分类的原有字距不应改变。

## 4. 地图显示名刷新

1. 中文环境创建一个采用系统建议名称的书签，记录其区域、内部地图名和坐标。
2. 切换英文后查看详情：用户书签名称保持原样，但 `Area` 优先显示当前英文地图名，`Map` 保持稳定内部名称。
3. 确认该变化仅影响显示，不会新增、删除或重命名书签。

## 5. 缩放回归

分别在 100%、125%、150% UI 缩放下打开英文手册，至少检查：

- `Quick Access` 与 `Hidden`；
- `Defaults` 的地点详情；
- `Hidden` 的空状态；
- 一个较长的中英混合书签名。

记录任何重叠、越界、裁切或点击区域错位。

## 6. 生成候选发布包

完成上述验证后运行：

```powershell
.\scripts\Package-Windows.ps1
```

确认生成 `dist\WarpBookmarks-1.0.1.zip`，并保存脚本输出的 SHA-256。

`Package-Windows.ps1` 没有 `-Install` 参数。安装测试使用 `Build-Windows.ps1 -Install`，生成最终 ZIP 时单独运行上面的打包命令。

## 7. 最终 ZIP 干净安装

1. 退出游戏和 SMAPI。
2. 删除或暂时移走 `Mods\WarpBookmarks`，再从刚生成的 `WarpBookmarks-1.0.1.zip` 解压安装。
3. 确认最终路径为 `Mods\WarpBookmarks\WarpBookmarks.dll`，不是双层 `WarpBookmarks` 目录。
4. 重新载入原存档，确认旧书签、常用状态与隐藏状态未丢失。
5. 再执行一次记录、重命名和传送，并确认 SMAPI 没有本 Mod 的红色错误。

个人书签和相关状态保存在玩家存档的 `modData` 中，不保存在 Mod 安装目录；替换或删除 `Mods\WarpBookmarks` 不会主动删除这些数据。尽管如此，发布测试前保留正常的存档备份仍是稳妥做法。
