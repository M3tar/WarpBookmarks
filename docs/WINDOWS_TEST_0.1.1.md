# 传送书签 0.1.1：Windows 单次测试

这一版不要求多个存档、多个鸡舍、睡觉保存或联机。请只用当前单人存档，在一次游戏过程中检查完整功能链路。

## 1. 构建并覆盖安装

在解压后的项目目录运行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\Build-Windows.ps1 -Install
```

脚本会在目标文件夹确实属于 `Mercury.WarpBookmarks` 时安全覆盖旧版，不再要求额外添加 `-UpdateExisting`。

## 2. 一次游戏内检查

1. 载入现有单人存档，确认 SMAPI 显示 `Warp Bookmarks 0.1.1 vertical slice loaded`，且没有红色报错。
2. 按 `Shift + K`，应记录当前位置并显示书签名称。
3. 走到另一个普通地点，再按一次 `Shift + K`，创建第二个书签。
4. 按 `K` 打开传送手册：应至少看到“返回住宅”“农场图腾”和刚创建的两个书签；去过的山区、海滩、沙漠或姜岛会按访问记录出现。
5. 选中一个书签，分别试一次收藏、重命名，然后点击传送。
6. 再按 `K`，选择“上一个位置”，应返回刚才的出发格附近。
7. 选择“返回住宅”，应落在当前角色自己的住宅门外；若原格被占用，允许落在附近三格内。
8. 对自定义书签点击两次“删除”；对默认地点点击两次“隐藏”；再点“恢复默认地点”。
9. 可选：在 SMAPI 控制台输入 `wb_warp Town 42 68`，验证精准坐标后端和安全落点。坐标输入界面将在下一批接入手册。

## 3. 请发回什么

只需要发两样，不必逐项写长报告：

- 从游戏启动到完成上述操作的 SMAPI 日志；
- 一句话说明最明显的不对之处，例如“返回住宅落点不对”或“界面按钮超出屏幕”。

若游戏在某一步报错，请注明当时点了哪个按钮。其余未提到的步骤会视为基本通过。
