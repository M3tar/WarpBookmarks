# 传送书签 0.5.0 Windows 合并测试

本轮主要验证手册操作层级和长列表体验，不需要多个存档或联机成员。覆盖安装后使用任意单人存档即可。

## 构建与安装

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\Build-Windows.ps1 -Install
```

确认 SMAPI 启动日志显示 `Warp Bookmarks 0.5.0`，且没有红色错误。

## 1. 主要传送操作

1. 按 K 打开手册并选择任意可用地点。
2. 右下角应显示“传送到「地点名称」”，名称随列表选择立即变化。
3. 点击该按钮，应传送到当前显示的地点。
4. “输入坐标…”位于左下角，与“记录当前位置”并列；点击后才进入精准坐标窗口。
5. 返回手册后，确认详情区不再出现第二个“传送”按钮。
6. 选择“已隐藏”地点时，右下角主按钮应不可用，不允许传送。

## 2. 详情区管理操作

1. 自定义书签详情显示“收藏/取消收藏、重命名、删除”三个同组按钮。
2. 可见默认地点详情显示“收藏/取消收藏、隐藏”。隐藏仍需点击两次确认。
3. 进入“已隐藏”分类，选中默认地点后显示“恢复这个地点”和“恢复全部默认地点”。
4. 恢复单个地点后，其他隐藏地点仍保留；恢复全部后，“已隐藏”分类显示空状态且不再显示恢复按钮。
5. 其他分类中不应出现“恢复全部默认地点”。

## 3. 长书签列表

如果当前列表已经超过六项，直接测试；否则本节可以跳过，不需要专门制作测试存档。

1. 列表超过可见行时，右侧应显示细滚动条。
2. 鼠标滚轮一次明显移动多项；点击滚动条轨道上方或下方应按页移动。
3. PageUp/PageDown 按页移动选择，Home/End 跳到第一项或最后一项。
4. 很长的书签名称在列表、详情标题和主按钮中应以省略号收尾，不应越过边框。

## 4. 基础回归

- K 打开/关闭手册，Shift+K 快速记录；
- 手册按钮记录和坐标保存仍然先命名；
- 常用、全部、我的书签、默认地点、已隐藏分类与搜索仍可组合；
- 精准坐标地图七行列表、搜索、滚动条、预览、保存和传送仍正常；
- 重命名窗口左右方向键仍是已知问题，本轮无需复测。
