# 项目状态

> 最后更新：2026-09-10 CST

## 0.1.0 可玩竖切

已实现 K/Shift+K 正式交互、当前玩家独立的书签持久化、自动命名与重命名、收藏、二次确认删除、默认地点隐藏与恢复、住宅门外解析、五类原版图腾目的地、上一个位置往返、三格安全落点，以及 `wb_warp <location> <x> <y>` 精准坐标后端。

下一批集中实现精准坐标图形界面、搜索与分类、图标/颜色编辑、更完整的访问权限和手柄焦点。

`0.1.1` 修复首次 Windows 构建发现的 `LocationPolicy` 缺少 SMAPI 命名空间问题，并加入打包前的 C# 命名空间回归检查。

`0.1.1` 单人实测已通过快速记录、重命名、收藏、传送、自定义书签删除，以及默认地点隐藏/恢复。`0.1.2` 根据实测移除山景菜单背景，改用文档指定的原版 `letterBG` 羊皮纸；操作按钮改为栏内动态双列布局，并区分“确认删除”和“确认隐藏”。

`0.2.0` 新增手册即时搜索和精准坐标图形界面。坐标输入必须先预览，并继续经过统一的访问限制、特殊地图拦截和三格安全落点；验证后可直接传送或保存为个人书签。

`0.2.1` 根据实测将坐标地图内部名称输入改成“已到访地图”下拉列表，X/Y 拆分为两个输入框；修复文本框焦点下左右方向键被基础菜单处理的问题，并用自有羊皮纸重命名窗口替换原版 `NamingMenu`。

`0.2.2` 根据复测撤销 X/Y 的方向键和 Tab 自动切换，字段只能通过鼠标点击获得焦点；下拉地图加入按显示名或内部名称即时搜索。重命名框的左右光标键在原版和自定义文本框中均未生效，暂列已知问题，避免继续加入未经实机证实的反射式光标修改。

`0.3.0` 将底部按钮文案改为“精准坐标传送”，并重新分配三个底部按钮宽度。手册新增“全部、收藏、我的书签、默认地点、已隐藏”分类；分类可与搜索组合，默认地点可以在“已隐藏”中逐个恢复，也可继续一键全部恢复。

`0.4.0` 将首页调整为“常用”，固定显示返回住宅、上一个位置和玩家收藏；同一次游戏会话中重新打开手册会回到上次分类，但不会保留搜索词。精准坐标地图下拉框扩展为七行，加入滚动条、三项滚动和分页点击。手册按钮记录与坐标保存现在都先打开空白命名窗口，并提供可一键采用的建议名称；Shift+K 继续直接快速记录。

`0.5.0` 重构手册操作层级：底部右侧成为唯一的动态“传送到某地”主按钮，记录当前位置与“输入坐标…”归为左侧次级工具；收藏、重命名、删除和隐藏留在详情区。“恢复这个地点 / 恢复全部默认地点”只在“已隐藏”分类显示。主地点列表新增滚动条、三项滚轮移动、分页点击，以及 PageUp、PageDown、Home、End 键导航；长名称和动态主按钮会自动省略，避免文字超框。

`0.5.1` 根据实机观感取消主传送按钮的深金色填充和自定义深棕文字，启用状态统一使用原版白色按钮与 `Game1.textColor`，禁用状态继续明确变灰。移除载入存档时左下角快捷键 HUD 及其配置项；手册内部仍根据 `OpenMenuKey` 和 `CreateBookmarkKey` 动态显示“打开/关闭手册、快速记录”。配置版本升至 4，以清理旧的提示开关字段。

`0.5.2` 修复精准坐标和自动命名书签的成功 HUD 重复坐标：普通成功提示只显示目的地名称；仅当三格安全检查改变落点时，才追加“安全落点调整为（X, Y）”。新增跨 `CoordinateWarpDialog → WarpService → i18n` 的格式回归检查，并将 PowerShell 语法守卫扩展到全部测试脚本。

`0.5.3` 修复进程内书签缓存没有记录数据归属的风险。缓存现在绑定存档目录、农场唯一编号、玩家联机 ID 与 SMAPI 屏幕；读取时如果归属变化会丢弃旧缓存，写入前也会再次校验并拒绝跨玩家写入。`wb_dump_bookmarks` 新增归属诊断信息，并加入持久化隔离回归检查。

`0.5.3` 已由用户在在线联机环境复测，新书签没有再与个人存档串用，使用过程没有发现其他问题。

`1.0.0` 不增加新玩法，以 `0.5.3` 为功能基线进入发布准备：补充双语说明、CHANGELOG、Nexus Mods 页面草稿、发布清单、Windows 最终冒烟和只包含 DLL/manifest/i18n 的一键打包脚本。

`1.0.1` 修复英文界面的本地化布局：分类栏改为横跨手册，右侧详情下移并约束长文本；详情标点交给 i18n。用户保存的中文书签名在拉丁语言界面中按需使用游戏中文界面的 `SmallFont` 绘制，地图显示名则根据稳定内部地图名按当前语言刷新，原始书签数据保持不变。常用状态改为行末固定像素星标，英文语义统一为 `Quick Access / Pin / Unpin`，搜索提示移入输入框内部。精准坐标下拉箭头改为字体无关的像素图形，中文传送按钮移除缺字括号，主列表滚动条与六行内容对齐，中文“我的书签”精简为“书签”。

## 当前阶段

`1.0.0` 已发布至 [Nexus Mods](https://www.nexusmods.com/stardewvalley/mods/50310?published=1)（Mod ID `50310`）。Windows 已生成并实测 `1.0.1` 最终安装包：干净安装后旧书签与常用状态保留，SMAPI 没有本 Mod 红色错误，中文书签的 HUD 提示不再出现 `?`。安装包结构、版本、i18n 与 SHA-256 已完成仓库审核，中英文 README 已切换为 `1.0.1` 内容。当前等待作者确认最终差异，再推送并创建 GitHub Release。

## 已完成

- 确认项目名、项目路径与 UniqueID；
- 完成产品、UI、技术、开发和测试计划；
- 确认不使用实体道具、升级、充能或共享书签；
- 默认 K 打开手册、Shift+K 记录位置且支持改键；旧测试绑定自动迁移；
- 手册内部显示当前实际快捷键；载入存档时不再弹出 HUD 提示；
- 确认返回个人住宅门外；
- 确认严格访问控制；
- 确认首版默认地点为农场、山区、海滩、沙漠和姜岛五种标准传送图腾目的地；
- 建立 net6.0 / SMAPI 4.5.2 工程骨架、manifest、中英文 i18n 和 GMCM 接口；
- 建立位置身份、格子 API/占用和每玩家 `modData` 持久化探针；
- 建立安全 Windows 构建/安装脚本与阶段 0 验证文档。
- 修复 Windows PowerShell 解析失败：`Find-GamePath` 不再把 `-and` 放在续行开头，改为显式程序集路径变量和单行条件。
- 新增 `scripts/Test-PowerShellSyntax.ps1` 回归检查；修复后的完整构建脚本已通过 PowerShell 7.7 解析器验证，无语法错误。
- Windows 实测发现 F4/Shift+F4 会触发原生截图模式；默认键改为 F6/Shift+F6，并加入版本化配置迁移，保留玩家自定义绑定。
- 根据用户反馈不再使用功能键，默认改为 T/Shift+T；输入改用 `ButtonsChanged` 并抑制已激活组合，避免重复触发和游戏同时处理。
- 用户进一步确认 T 可能承担其他输入功能，最终默认改为 K/Shift+K；0.0.4 启动日志会输出实际生效绑定，便于区分默认值与持久化配置。
