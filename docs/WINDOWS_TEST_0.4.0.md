# 传送书签 0.4.0 Windows 合并测试

本轮把多个改动集中验证，不需要准备多个存档、多个建筑或联机成员。请覆盖安装后载入任意单人存档。

## 构建与安装

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\Build-Windows.ps1 -Install
```

确认 SMAPI 启动日志显示 `Warp Bookmarks 0.4.0`，且没有红色错误。

## 1. 常用首页与分类记忆

1. 按 K 打开手册，确认默认是“常用”。
2. “常用”应显示“返回住宅”；若当前会话已有上一个位置，也显示“上一个位置”；收藏的自定义书签或默认地点也应出现。
3. 切换到“我的书签”，关闭并再次按 K，确认仍打开“我的书签”。
4. 在搜索框输入文字后关闭并重新打开，确认搜索词已经清空。
5. 取消某个地点的收藏后，如果当前在“常用”，该地点应离开列表；返回住宅和上一个位置不受影响。

## 2. 手册按钮记录时先命名

1. 点击“记录当前位置”，确认不会立即保存，而是打开命名窗口。
2. 输入框应为空，并显示建议名称、地图和坐标。
3. 不输入名称时“保存书签”不可用。
4. 自己输入一个新名称并保存，确认返回“我的书签”且新书签存在。
5. 再记录一次，点击“采用建议名称”后保存，确认建议名称可正常使用。
6. 按 Shift+K，确认仍然立即记录并显示自动名称，不打开命名窗口。

## 3. 精准坐标地图长列表

1. 点击“精准坐标传送”，展开目标地图。
2. 列表最多一次显示七个地图，而不是旧版四个。
3. 地图数量超过七个时，应看到右侧滚动条。
4. 鼠标滚轮每次应明显移动多项；点击滚动条上方或下方应按页移动。
5. 在搜索框输入中文显示名或英文内部名，结果应即时缩小；上下键与 Enter 仍可选择结果。

## 4. 坐标保存时先命名

1. 选择地图、输入合法 X/Y 并点击“预览”。
2. 点击“保存为书签”，确认进入同一个命名窗口，而不是立即用自动名称保存。
3. 取消命名应返回精准坐标窗口；重新输入合法目的地后仍可预览。
4. 输入名称并保存，应返回“我的书签”，且名称、地图、坐标正确。
5. 选中新书签传送，确认安全落点检查仍生效。

## 5. 基础回归

- K 打开/关闭手册，Shift+K 快速记录；
- 收藏、取消收藏、重命名、删除自定义书签；
- 隐藏默认地点、从“已隐藏”逐个恢复、恢复全部默认地点；
- 精准坐标 X/Y 只能用鼠标切换焦点，不再测试方向键或 Tab 切换；
- 重命名窗口左右方向键仍是已知问题，本轮无需复测。
