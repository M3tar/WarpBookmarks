# 传送书签：产品规格

> 文档状态：需求整理版 v0.1  
> 日期：2026-08-02  
> 目标：先确认规则，再进入实现

> `1.0.0` 范围修订（2026-08-06）：核心传送与个人书签保持不变；图标/颜色、收藏手动排序、删除撤销、失效书签提前标记与重新绑定、坐标复制/多格式粘贴、传送动画和完整手柄适配延后到 `1.x`。当前点击传送时的地图缺失、限制地图和安全落点错误提示作为首版失效安全保障。

## 1. 产品定位

“传送书签”是一个轻量的移动体验优化 Mod。它把地图位置保存成个人书签，让玩家减少重复赶路，同时避免实体道具、资源消耗和升级系统带来的负担。

它不是一个任意功能堆叠的作弊菜单。产品辨识度来自三个核心概念：

1. 可命名、收藏和管理的个人地点书签；
2. 可在两个地点间快速往返的“上一个位置”；
3. 同时支持名称搜索与地图格子坐标的传送手册。

## 2. 产品目标

1. 单人、联机主机和联机加入者都能使用相同的传送能力。
2. 每名玩家只看见和管理自己的书签。
3. 大量书签仍然容易搜索、排序、删除和恢复。
4. 原版地图、SVE 和常规自定义地图尽量使用通用位置标识兼容，不依赖写死坐标。
5. 传送不会把玩家放进水、墙、地图外或已占用的格子。
6. 地图、建筑或其他 Mod 改变后，旧书签不会悄悄传错位置。
7. 界面符合原版《星露谷物语》的羊皮纸视觉和操作习惯。

## 3. 明确非目标

首版不实现：

- 实体传送道具；
- 制作配方、充能、材料消耗、冷却和升级；
- 玩家之间共享书签；
- 传送到队友、拉取队友或集体传送；
- 自动追踪并直接传送到移动中的 NPC；
- 自动寻路、自动送礼或自动完成任务；
- 随机矿井层、节日地图、剧情地图和小游戏内部的自由传送；
- 在没有实测证据时承诺兼容所有大型扩展 Mod。

## 4. 核心传送入口

### 4.1 返回住宅

- 传送至当前玩家对应住宅的门外安全格。
- 农场主与联机加入者分别返回自己的住宅。
- 住宅移动或升级后每次重新解析，不使用永久写死坐标。
- 不传送到室内床边，减少房屋升级、家具和联机小屋布局带来的歧义。

### 4.2 自定义书签

玩家可在当前位置创建书签，并设置：

- 名称；
- 图标；
- 颜色；
- 是否收藏；
- 收藏顺序；
- 备注（后续可选，不列入首版必需）。

书签默认不设很小的硬性数量上限。地点库必须能够处理几十个书签；必要时只设置较高的技术保护上限，避免异常数据。

### 4.3 上一个位置

- 只记录通过本 Mod 成功传送时的出发位置。
- 失败或取消不更新记录。
- 使用后与当前位置交换，支持 A ⇄ B 往返。
- 普通步行不会覆盖它。
- 睡觉、昏迷、返回标题和重新读档后清空。
- 临时、剧情、节日、小游戏、随机矿井与特殊地牢房间不生成有效记录。

### 4.4 精准坐标

完整目标格式为“地图 + X + Y”，其中 X/Y 始终是地图格子坐标，不接受像素坐标。

支持：

- 下拉选择已知地图；
- 高级模式输入地图内部名称；
- 一次粘贴 `Town, 42, 68`、`Town 42 68` 或 `Town (42, 68)`；
- 默认使用当前地图，方便同地图移动；
- 仅传送；
- 传送成功后另存为书签；
- 复制当前位置为统一分享格式。

坐标传送必须先预览解析结果并由玩家确认，不因粘贴内容自动执行。

### 4.5 默认地点

首版内置原版五种标准传送图腾对应的目的地：

- 农场；
- 山区；
- 海滩；
- 沙漠；
- 姜岛。

范围依据：[Stardew Valley Wiki - Warp Totem](https://stardewvalleywiki.com/Warp_Totem)。

规则：

- 只显示玩家已经正常访问或解锁的安全公共入口；
- 不提前显示未解锁区域，避免剧透和跳过进度；
- 可以收藏和隐藏，不能修改系统坐标或永久删除；
- 已隐藏列表可逐个恢复或恢复全部；
- 更新默认坐标不得覆盖自定义书签。

默认地点应尽量复用或解析原版图腾的实际目的地数据，而不是复制一组未经验证的魔法数字。农场默认地点对应农场传送雕像；“返回住宅”仍是独立入口，落在个人住宅门外。

## 5. 地点管理规则

### 5.1 地点类型

| 类型 | 玩家操作 |
|---|---|
| 自定义书签 | 传送、收藏、编辑、复制、重新绑定、删除 |
| 默认地点 | 传送、收藏、复制、隐藏 |
| 上一个位置 | 传送、复制；不能编辑或删除 |
| 精准坐标结果 | 预览、传送、另存为书签 |

### 5.2 删除与恢复

- 自定义书签删除前确认，并提供当前会话内“撤销”。
- 删除收藏书签后保留空位，不自动打乱其他收藏顺序。
- 默认地点使用“隐藏”而非“删除”。
- 失效书签可以重新绑定到当前位置，不强迫删除。

### 5.3 重复地点

创建书签时检测同地图附近三格内的现有书签，提示但不禁止保存。默认地点不能被覆盖；自定义书签可选择覆盖。

## 6. 联机规则

- 联机兼容不等于共享网络。
- 每名玩家的书签、收藏、隐藏状态和上一个位置完全独立。
- 玩家名称变化不能导致数据丢失，应使用稳定玩家标识。
- 没安装 Mod 的玩家可以正常加入，只是没有传送功能。
- 多人同时到达相近目标时，分别寻找附近空闲格。
- 每位玩家独立判断事件、钓鱼、对话和其他禁止传送状态。
- 不实现队友位置显示、传送邀请或主机管理页面。

## 7. 访问权限原则

默认采用严格访问策略：只允许前往当前玩家已经正常解锁且当前允许进入的地图，避免精准坐标绕过沙漠、姜岛、下水道、NPC 房间和剧情区域。

严格检查包括：

- 建筑营业时间；
- NPC 卧室好感度门槛；
- 已访问建筑当前是否允许进入；
- 区域主线解锁状态。

无法可靠判断第三方地图权限时，系统应宁可拒绝并说明原因，不静默绕过。

## 8. 成功标准

玩家应能在不打开背包、不管理资源的情况下：

1. 打开传送手册；
2. 搜索或选择自己的地点；
3. 看懂目标地图、坐标、来源与可用状态；
4. 安全传送；
5. 返回刚才的出发位置；
6. 在联机中保持自己的列表干净且不受他人影响。
