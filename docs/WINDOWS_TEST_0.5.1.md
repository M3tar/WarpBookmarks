# 传送书签 0.5.1 Windows 合并测试

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\Build-Windows.ps1 -Install
```

确认 SMAPI 启动日志显示 `Warp Bookmarks 0.5.1`，且没有红色错误。

## 本轮重点

1. 载入存档时，左下角不再出现传送书签的快捷键 HUD 提示。
2. 按 K 打开手册；底部仍应显示当前按键及用途，例如“K 打开/关闭手册 · LeftShift + K 快速记录”。
3. 选择可传送地点后，右下角“传送到「地点名称」”应与其他可点击按钮一样明亮，不再是深金色。
4. 进入“已隐藏”或没有可用选择时，主传送按钮应明显变灰，且不能点击。
5. 鼠标移到可点击主按钮上时，仍有原版淡麦黄色悬停反馈。

## 自定义按键检查

如果方便，可在 GMCM 中临时修改“打开传送手册”或“记录当前位置”，重新打开手册后确认底部文案立即显示新按键。此项不要求准备额外存档；不方便改键时可以跳过。

其余 0.5.0 的传送、记录、坐标、分类、恢复和长列表功能做正常使用回归即可。重命名左右方向键仍是已知问题，本轮无需复测。
